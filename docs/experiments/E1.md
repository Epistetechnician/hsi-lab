# E1 — typed-event vs text codec at equal bytes

Packet: `packets/e1-v1.frozen.json` (byte budget 200, threshold +0.05, 4 full-observation families).

Setup: a random-exploration teacher trace of the same hidden-rule world is encoded by each codec,
truncated to the largest whole-step prefix within the byte budget (header, schema and provenance
counted), decoded, and fed to a scripted inductive learner that infers per-action primitives and
plans. Both codecs are lossless; the only difference is how many transitions fit.

Result (local run, see `docs/experiments/E1-receipt.json`): see receipt for the exact numbers.
Pilot σ≈0.46 → n=324 per family. The effect is large because the text codec spends ~35 bytes per
step against ~3 for typed events, so the learner sees ~5 vs ~40 transitions. This validates the
harness; it is **not** evidence that learned or real-world codecs behave this way.

Nonclaims: synthetic scripted agent only; no learned-latent arm (F7, P1); no claim beyond
`LocalSyntheticExperimentOnly`.

Reproduce:

```
export HSI_RUN_ROOT=~/hsi-runs HSI_CUSTODY_ROOT=~/hsi-custody
F=packets/e1-v1.frozen.json
hsi pilot $F && hsi lock $F && hsi run $F
hsi eval $HSI_RUN_ROOT/<digest16> && hsi verify-receipt $HSI_RUN_ROOT/<digest16>/eval/receipt.json
hsi decide <receipt> PROMOTE
```

Committed receipt: typed_event − text = +0.640 [0.614, 0.667], PROMOTE. Held-out cohorts are drawn from a random lock salt, so a re-lock changes the numbers slightly (decisions were stable across two locks); an exact clean-rerun match needs the same custody lock (M6).
