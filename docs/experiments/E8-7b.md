# E8-7b (packet e8-v4): the same question on a competent 7B generator

Qwen2.5-7B-Instruct bf16 (Apache-2.0), PyTorch/CUDA on one H100, LoRA r=8. Chains: plus x3, ex x3, none x1, depth
2, K=6, quota 100, lr 5e-5, 100 steps. Held-out: 405 tasks in 5 families of 81 (3 MBPP+, 2 HumanEval+), all
scored under the EvalPlus tests. Source commit `c9da714` (clean). Receipt `E8-7b-receipt.json`, digest
`1452688fb4…`, recomputed OK by the stdlib validator (A2). ADR 0007 (scope), ADR 0004/0005 (design).

## Result: NO_CANDIDATE
Primary d2_plus minus d2_ex: **-0.0025, 95% CI [-0.025, +0.020]**, threshold +0.03. The whole interval is below
the bar, so the pre-registered rule returns NO_CANDIDATE. Guardrail held (d2_plus 0.674 vs d1_plus 0.669).

| arm | pass@1 (n = 405) |
| --- | --- |
| frozen base | 0.674 |
| d1 none / ex / plus | 0.635 / 0.677 / 0.669 |
| d2 none / ex / plus | 0.664 / 0.677 / 0.674 |

Secondary (Bonferroni z=2.50, exploratory): d2 plus-none +0.010 [-0.020, 0.040]; ex-none +0.012 [-0.017, 0.042];
plus-frozen_base 0.000 [-0.030, 0.030]; d1 plus-ex -0.007 [-0.034, 0.019]. Kept-set precision: none 72-74%,
ex 80-91%, plus 100%.

## Reading
- **Test strength does not matter here, and the interval is tight enough to say so**: strong tests are no better
  than the one shown example by more than +0.02 on 405 tasks (the earlier 1.5B pooled interval was +/-0.043).
- **Nothing helps and nothing hurts.** Every 7B arm is within about 0.04 of the untouched base (0.674), including
  the unfiltered chains. Unlike the 1.5B model, the 7B is not damaged by training on its own unverified code
  (d2 none 0.664), but it also gains nothing from verified code. This recipe cannot improve a competent
  generator on these benchmarks.
- So across three studies: in synthetic rule worlds verifier precision pays; in code it pays a little for a
  small model (any test beats none) and not at all for a competent one. The synthetic result does not
  carry over to code self-training at this scale.

## Limits
One 7B model, a recipe that mostly leaves the model unchanged (100 LoRA steps on 100 examples), MBPP+ and
HumanEval+ possibly seen in pretraining, public held-out pool. Linux sandbox has no network block (the macOS
sandbox does). Torch runtime: a replication stack, not digest-comparable with MLX. A3 not possible (lock secret
deleted with the node). Not independent validation (A4).
